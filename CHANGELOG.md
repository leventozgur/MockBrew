## [Unreleased]

### Added

- **0.1.0 (not yet released):** model parsing and schema-based sample generation for Kotlin (Gson, Kotlinx Serialization, Moshi) and Swift Codable.
- Local mock serving with collections, response scenarios, CORS, a web dashboard, CLI, and project files compatible with the mock engine.
- Stdio MCP server with narrowly scoped tools for listing collections, parsing models, generating and validating samples, and saving scenarios.
- Optional GitHub Copilot CLI generation with prompt preview, hash approval, process isolation, and local fallback.
- Proxy fallback, explicit LAN binding controls, model-change checking, and OpenAPI 3.1 export.
- Safe mode, loopback-only Control API, masked logs, and no telemetry.

The 0.1.0 version has not been released.
